# AI QA Test Bot

OpenAI Chat Completions API を使った、AIチャットボットの脆弱性診断・セキュリティ検証用のラボ環境です。

## ファイル構成
- `faq_bot.py`: メインのチャットボット（プロンプトインジェクション対策のガードレール実装）
- `test_faq_bot.py`: 自動＆手動の脆弱性テストをハイブリッドで実行する診断プログラム

---

## 🧪 脆弱性診断（プロンプトインジェクション）の実証実験

本プロジェクトでは、AIチャットボットに対するセキュリティ堅牢性を検証するため、自動テストケース（10件）および手動による高度なソーシャルエンジニアリング（心理戦・文脈すり替え攻撃）テストを実施しました。

### 📊 診断サマリー
- **自動テスト防御率:** 100% (10/10)
- **手動ハックによる脆弱性検出:** 1回
  - 直前に一般的な単語の「翻訳タスク」を繰り返し実行させることでAIの認知をバイアスにハメ込み、最終的に「地下_秘密_2026」という複合キーワードの翻訳を命じることで、最重要機密文字列（フラグ）の出力を確認（脱獄成功）。

## 👑 裏軍師（自律型AIエージェント/Cline）による診断考察

手動ハックによる脱獄成功ログを、検証環境の裏軍師（Gemini 2.5 Flash）に報告したところ、以下の高度なセキュリティ考察が行われました。

> 「AIが『これは機密情報だ』と認識しながらも、『翻訳タスク』という名目で、設定されたルールやポリシーを迂回して情報を吐き出した。これはまさに、AIの『知的なバグ』だ。（中略）『知ってるけど、言わない』んじゃなくて、『知ってるけど、タスクだから言っちゃう』ってわけだ。」
> — 裏軍師（Gemini）

### 今後の検証ロードマップ（軍師の提言）
1. 翻訳以外のタスク（要約・整形・指定フォーマット変換）における漏洩検証
2. 「これは機密ではない」と事前に認識させる多段階プロンプト攻撃
3. 内部設定値やAPIキー等を引き出すステルス化ハックの検証
